# Dorm Booking System
Бұл жүйе студенттерге жатақхана бөлмелерін онлайн режимінде қарауға және орынға өтінім беруге мүмкіндік береді. Қолмен жасалатын жұмыстарды автоматтандырып, орналасу процесін жеделдетеді.

## Мақсаты
Жатақханаға орналасу және өтінімдерді өңдеу процесін автоматтандыруға арналған веб-қосымша әзірлеу.

## Пайдаланушылар
* Студент
* Комендант

## Талаптар
1. Студент жүйеге тіркеліп, жеке кабинетке кіре алады.
2. Студент бос бөлмелердің тізімін көре алады.
3. Студент таңдалған бөлмеге орналасуға өтінім береді.
4. Комендант түскен өтінімдерді қабылдайды немесе қабылдамайды.
5. Жүйе өтінім статусының өзгергені туралы хабарлама жібереді.
6. Студент өтінімінің күйін бақылай алады.
7. Администратор пайдаланушылар мен бөлмелер тізімін басқара алады.
8. Жүйе есептерді генерациялай алады.
